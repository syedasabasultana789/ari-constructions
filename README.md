## Run locally
1. Install Node.js 22.22.3+.
2. Run `npm install`.
3. Run `npm start`.
4. Open the local URL shown by Angular CLI.

## Production build
Run:
`npm run build`

The static production output is created under `dist/ari-constructions` and can be uploaded to a static hosting provider.

## Replace project photos
Put your own photos in `src/assets/images/` and change the image paths/URLs in `src/main.ts`. The ARI logo is already included as `src/assets/images/ari-logo.png`.

## Hosting
This project is configured with Angular static output. It can be hosted on Netlify, Vercel, Firebase Hosting, GitHub Pages, or a normal web server/CDN. If using Angular routes later, configure the host to fall back to `index.html`.
